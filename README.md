# CreFetch - 高速多线程下载器

**CreFetch** 是一款基于 .NET 10 开发的 Windows 桌面下载工具。它通过监控剪贴板自动嗅探下载链接，利用多线程分块下载技术，极大提升下载速度，并拥有智能断点续传等特点


---

## 核心特性

- **多线程极速下载**：支持自定义 1~128 个线程并发分块下载，榨干宽带。
- **剪贴板自动嗅探**：复制链接即可自动检测，无需手动粘贴。
- **智能断点续传**：支持暂停/继续，停机/崩溃后再次打开也能从断点恢复。
- **开机静默自启**：支持注册表启动，开机后自动隐藏到系统托盘。

---

## 使用指南

1. **下载并运行**：下载发布页的 `win-x64.zip`，解压后双击运行 `CreFetch.exe`。
2. **复制链接**：随便复制一个浏览器里的下载链接（如 `https://.../xxx.zip`）。
3. **自动捕捉**：CreFetch 会弹窗询问你是否加入下载队列。
4. **开始下载**：点击“是”，程序会自动开始多线程下载，并在主窗口实时显示进度。
5. **后台运行**：点击窗口的“关闭”按钮会最小化到系统托盘；右键托盘图标可“退出”。

---

## 参数配置 (config.ini)

程序首次运行时，会在同目录下自动生成 `config.ini` 文件，你可以在“设置”界面中修改，也可以手动修改该文件：

```ini
[Download]
max_threads = 50         ; 下载线程数
save_path = C:\...       ; 文件保存路径
timeout = 30             ; 网络请求超时时间 (秒)

[Behavior]
prompt_mode = 始终询问   ; 可选：始终询问 / 自动添加 / 智能提示
smart_threshold_mb = 50  ; 智能模式下的文件阈值 (MB)

[App]
auto_start = false       ; 是否开机自启 (true / false)
show_notification = true ; 是否显示通知弹窗
```
